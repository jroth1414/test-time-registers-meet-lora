# Register-Aware PEFT Study: Master Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **This file is an index.** Do not load every chunk at once. Load this file plus exactly one chunk file (`2026-09-02-0N-*.md`) per working session. Each chunk is self-contained: it restates the interfaces it consumes and produces.

**Goal:** Build the experiment code that tests whether ViT register artifacts survive LoRA fine-tuning and whether training-free test-time registers repair dense prediction, across DINOv2/CLIP backbones and ADE20K/Cityscapes/LaRS.

**Architecture:** A single Python package `ttr` wraps timm `VisionTransformer` models (DINOv2 with and without trained registers, CLIP ViT-B/16 via timm's `vit_base_patch16_clip_224.openai`) behind one `Backbone` class that exposes patch-token grids, per-layer hooks, optional appended test-time register tokens, and an in-house LoRA wrapper on the fused `qkv`/`proj` linears. Segmentation heads, datasets, metrics, and a config-driven runner sit on top; every run writes `results/<run_id>/metrics.json` and an aggregation script turns those into the paper's tables and hypothesis checks.

**Tech Stack:** Python 3.11, PyTorch 2.7+ with CUDA 12.8 wheels (RTX 5070 Ti is Blackwell, sm_120), timm, torchvision, OmegaConf (YAML configs over dataclasses), pytest, ruff, pandas, scipy, matplotlib. No Hugging Face `peft` (LoRA is ~80 lines in-house and needs slice-level targeting timm's fused qkv cannot give through peft).

**Spec:** `proposal/proposal.tex` (the design) and `CLAUDE.md` section "Experimental design" (the factorial, datasets, diagnostics, sweeps).

## Global Constraints

- Python 3.11.9 on Windows 11; PowerShell is the primary shell, Git Bash exists. All commands in chunk files are written for PowerShell unless marked.
- One local GPU with 16 GB (RTX 5070 Ti). Anything above ViT-B or above 518 px input must use gradient checkpointing or be marked "cloud only".
- Tests must run on CPU in under 60 s total, using tiny randomly initialised ViTs (embed_dim 32, depth 2-4, patch 14, img 56). Never download weights inside a test.
- Every backbone is a timm `VisionTransformer`. Never add a second model-family code path.
- Token layout inside `Backbone` is always `[cls] [trained regs...] [test-time regs...] [patches...]`. The counts are exposed as `num_cls`, `num_trained_reg`, `num_tt_reg`, `num_patches`.
- All randomness flows through `ttr.utils.seed_everything(seed)`; every run config carries `seed`.
- Results are written to `results/<run_id>/` as `config.yaml`, `metrics.json`, `diagnostics.json`, `log.csv`. `results/` is committed except `*.pt` files. `data/` is gitignored.
- Commits are authored by John Roth with no Claude trailers (`.claude/settings.json` enforces this; never add them by hand). Commit at the end of every task. Use conventional prefixes `feat:`, `test:`, `chore:`, `docs:`.
- Prose in docs follows the stop-slop rules already applied to the proposal.
- The 10/19 draft needs the ADE20K factorial finished. Chunks 1-7 are on that critical path; chunk 8 (mask head) and chunk 9 (Cityscapes/LaRS) come after.

## Shared interfaces (the contract every chunk restates)

```python
# ttr/config.py  (chunk 1)
@dataclass
class BackboneCfg:
    name: str = "vit_small_patch14_dinov2.lvd142m"   # any timm VisionTransformer name, or "tiny" for tests
    img_size: int = 224
    pretrained: bool = True
    registers: str = "none"           # "none" | "test_time" | "trained"
    num_test_time_registers: int = 1
    register_neuron_path: str | None = None   # JSON produced by chunk 3 detector
    outlier_layer: int = -1           # residual layer for tau calibration; model-specific (vits 10, vitb 8, clipb 11)
    capture_attention: bool = False

@dataclass
class LoraCfg:
    enabled: bool = False
    r: int = 8
    alpha: float = 16.0
    targets: list[str] = field(default_factory=lambda: ["q", "v"])   # subset of {"q","k","v","o"}
    layers: Any = "all"               # "all" or list[int]; Any because OmegaConf rejects unions
    dropout: float = 0.0

@dataclass
class HeadCfg:
    type: str = "linear"              # "linear" | "mask"
    hidden: int = 256                 # mask head only

@dataclass
class DataCfg:
    name: str = "ade20k"              # "ade20k" | "cityscapes" | "lars" | "synthetic"
    root: str = "data/ade20k"
    img_size: int = 224
    batch_size: int = 16
    num_workers: int = 4
    calib_images: int = 64            # for outlier threshold + register neurons
    diag_images: int = 512            # images used by the post-training diagnostics (outlier fractions)
    mean: list[float] = field(default_factory=lambda: [0.485, 0.456, 0.406])  # runner overwrites from timm pretrained_cfg
    std: list[float] = field(default_factory=lambda: [0.229, 0.224, 0.225])

@dataclass
class TrainCfg:
    mode: str = "frozen"              # "frozen" | "lora" | "full"
    epochs: int = 10
    lr: float = 1e-3
    lr_backbone: float = 1e-5         # full mode only
    weight_decay: float = 0.01
    amp: bool = True
    grad_checkpoint: bool = False
    seed: int = 0

@dataclass
class RunCfg:
    run_id: str = "debug"
    out_dir: str = "results"
    backbone: BackboneCfg = field(default_factory=BackboneCfg)
    lora: LoraCfg = field(default_factory=LoraCfg)
    head: HeadCfg = field(default_factory=HeadCfg)
    data: DataCfg = field(default_factory=DataCfg)
    train: TrainCfg = field(default_factory=TrainCfg)
    diagnostics: bool = True
```

```python
# ttr/backbone.py  (chunk 2)
class Backbone(nn.Module):
    embed_dim: int; depth: int; patch_size: int; grid: tuple[int, int]
    num_cls: int; num_trained_reg: int; num_tt_reg: int; num_patches: int
    def forward_tokens(self, x: Tensor) -> Tensor            # (B, T, C) after final norm
    def forward_features(self, x: Tensor) -> Tensor          # (B, C, h, w) patch grid
    def patch_slice(self) -> slice                            # indices of patch tokens
    def tt_reg_slice(self) -> slice
    def capture(self, what: str, layers: list[int]) -> "CaptureHandle"   # what in {"resid","mlp_act","attn"}
    def set_tt_registers(self, n: int) -> None
    def add_mlp_hook(self, layer: int, fn) -> torch.utils.hooks.RemovableHandle
def build_backbone(cfg: BackboneCfg) -> Backbone
def tiny_backbone(depth=2, embed_dim=32, heads=2, img=56, reg_tokens=0) -> Backbone  # tests only
```
